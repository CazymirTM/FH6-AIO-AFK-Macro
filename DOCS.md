# 🔒 FH6 Macro is Now Semi-Private

Hey everyone! 👋

First of all, I'm sorry for making this change. I know some of you probably expected the macro to stay fully public, and I really didn't want to go this route.

Unfortunately, with how **Forza Horizon 6** is evolving, more and more things are being monitored (API usage, login behavior, and other methods that pretty much every macro relies on in one way or another). Keeping everything public makes it much easier for these methods to be discovered and patched.

I genuinely want to keep improving the macro and keep it alive for as long as possible, so for now **the latest versions will be semi-private.** ❤️

---

## 🚀 How to get access

Getting access is simple!

Just contact me by either:

- 💬 Sending me a DM on Discord
- 🌐 Joining my Discord server and opening a ticket / sending me a message

When you contact me, please include a screenshot showing your **Steam or Xbox playtime** for **Forza Horizon 6**.

### 📌 Requirement

- ⏱️ At least **20 hours** played in Forza Horizon 6.

This requirement exists due to current circumstances and **will remain in place**. It's mainly here to help filter out throwaway accounts and keep PG games from seeing these rise in newer accounts.
